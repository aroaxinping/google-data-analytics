# Course 4 — Process Data from Dirty to Clean

**Duracion:** 16 horas | **Modulos:** 6 | **Fase del proceso:** Process

La fase Process del proceso de analisis: como detectar y corregir datos sucios con Sheets y SQL, como verificar que la limpieza fue correcta y como documentar todo el proceso de limpieza para que sea reproducible y auditable.

## Contenido del curso

- Modulo 1: The Importance of Integrity — integridad de datos, muestreo aleatorio, margen de error e hipotesis estadistica
- Modulo 2: Clean Data for More Accurate Insights — tipos de datos sucios y funciones de limpieza en Sheets
- Modulo 3: Data Cleaning with SQL — TRIM, LOWER, CAST, COALESCE y ROW_NUMBER en BigQuery
- Modulo 4: Verify and Report on Cleaning Results — proceso de verificacion y changelogs
- Modulo 5: Add Data to Your Resume — como reflejar habilidades de datos en el curriculum
- Modulo 6: Course Wrap-Up — resumen y glosario del curso

## Archivos

- `apuntes.md` — notas completas del curso con funciones de limpieza, SQL y errores comunes
- `proyecto-limpieza/` — proyecto practico de limpieza de un dataset real
