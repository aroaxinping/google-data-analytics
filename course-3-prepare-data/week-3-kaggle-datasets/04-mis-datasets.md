## Dataset 1: Job Salary Prediction Dataset

**URL:** https://www.kaggle.com/datasets/nalisha/job-salary-prediction-dataset

| Campo | Valor |
|-------|-------|
| Creador | Aleesha Nadeem |
| Archivos | 1 CSV · 3 MB |
| Usabilidad | 10.0 |
| Licencia | CC0: Public Domain |
| Votos | 187 |

### Por qué lo elegí
Contiene 250,000 registros de empleos con información sobre título,
nivel de experiencia, formación, habilidades, industria, tamaño de empresa
y salario. Útil para practicar análisis exploratorio y modelado predictivo.

### Posibles preguntas de análisis
- ¿Qué factores influyen más en el salario?
- ¿Qué sectores pagan mejor a nivel de entrada?
- ¿Hay diferencias salariales por tamaño de empresa?

| Licencia | CC0: Public Domain |

### Por qué lo elegí

valores faltantes, nombres de columnas inconsistentes, duplicados.
Perfecto para practicar limpieza de datos (Course 4).

### Problemas de calidad presentes
- Missing values
- Inconsistent column names
- Duplicate entries
- Formatting issues

## Dataset 3: Netflix Movies and TV Shows

**URL:** https://www.kaggle.com/datasets/shivamb/netflix-shows

| Campo | Valor |
|-------|-------|
| Creador | Shivam Bansal |
| Archivos | 1 CSV · 1 MB |
| Usabilidad | 10.0 |
| Licencia | CC0: Public Domain |
| Votos | 9,802 |
| Frecuencia | Quarterly |

### Por qué lo elegí
Uno de los datasets más populares de Kaggle (9,802 votos). Catálogo
completo de películas y series de Netflix con fechas, géneros, países
y clasificaciones. Muy visual y fácil de comunicar resultados.

### Posibles preguntas de análisis
- ¿Qué tipo de contenido produce más Netflix: películas o series?
- ¿En qué países se produce más contenido?
- ¿Cómo ha evolucionado el catálogo por año?
