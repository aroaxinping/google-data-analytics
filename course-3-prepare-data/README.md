# Course 3 — Prepare Data for Exploration

**Duracion:** 19 horas | **Modulos:** 5 | **Fase del proceso:** Prepare

La fase Prepare del proceso de analisis: como se generan y estructuran los datos, como evaluarlos con el framework ROCCC, como acceder a bases de datos con SQL basico en BigQuery, y como organizar y proteger datos correctamente.

## Contenido del curso

- Modulo 1: Data Types and Structures — datos estructurados vs no estructurados, tipos de dato, formatos y la diferencia entre datos largos y amplios
- Modulo 2: Data Responsibility — sesgo, credibilidad con ROCCC, etica de datos y datos abiertos
- Modulo 3: Database Essentials — bases de datos relacionales, metadatos, SQL con BigQuery y ordenacion y filtrado
- Modulo 4: Organize and Protect Data — convencion de nombres, niveles de acceso y seguridad de datos

## Archivos

- `actividad-roccc/` — practica de evaluacion de fuentes de datos con ROCCC
