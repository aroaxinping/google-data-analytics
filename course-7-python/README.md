# Course 7 — Introduction to Data Analysis Using Python

**Duracion:** 27 horas | **Modulos:** 4 | **Fase del proceso:** (Transversal)

> Nota: el certificado se actualizo en 2024 y cambio este curso de R a Python. La carpeta se llama "course-7-python" por razones historicas.

Introduccion a Python para el analisis de datos: desde la sintaxis basica hasta el uso de pandas y NumPy para manipular, limpiar y visualizar datos. Es el curso mas largo del certificado.

## Contenido del curso

- Modulo 1: Hello, Python! — tipos de datos, variables, Jupyter Notebooks y programacion orientada a objetos
- Modulo 2: Functions and Conditional Statements — funciones, parametros, condicionales y estilo PEP 8
- Modulo 3: Loops and Strings — bucles while y for, range(), indexacion, slicing y metodos de string
- Modulo 4: Data Structures in Python — listas, tuplas, diccionarios, sets, NumPy arrays y DataFrames de pandas
