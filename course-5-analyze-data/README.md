# Course 5 — Analyze Data to Answer Questions

**Duracion:** 26 horas | **Modulos:** 4 | **Fase del proceso:** Analyze

La fase Analyze del proceso de analisis: organizar, formatear, combinar y calcular con datos para responder preguntas de negocio. Es el curso de SQL mas avanzado del certificado, con JOINs, GROUP BY, funciones de ventana y CTEs.

## Contenido del curso

- Modulo 1: Organize Data for More Effective Analysis — ordenacion, filtrado y segmentacion con CASE
- Modulo 2: Format and Adjust Data — conversiones de tipo, fechas y JOINs
- Modulo 3: Aggregate Data for Analysis — GROUP BY, HAVING, funciones de ventana y subconsultas
- Modulo 4: Perform Data Calculations — formulas avanzadas en Sheets y CTEs en SQL
