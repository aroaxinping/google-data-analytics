# Course 2 — Ask Questions to Make Data-Driven Decisions

**Duracion:** 15 horas | **Modulos:** 4 | **Fase del proceso:** Ask

La fase Ask del proceso de analisis: como formular preguntas eficaces con el framework SMART, como los datos impulsan las decisiones de negocio, herramientas de Sheets para analisis y como comunicarse con stakeholders.

## Contenido del curso

- Modulo 1: Ask Effective Questions — framework SMART, tipos de problemas analiticos y pensamiento estructurado
- Modulo 2: Make Data-Driven Decisions — datos cualitativos vs cuantitativos, metricas, reports vs dashboards y big data vs small data
- Modulo 3: Spreadsheet Magic — funciones de Sheets, VLOOKUP, tablas pivot y manejo de errores
- Modulo 4: Always Remember the Stakeholder — comunicacion con ejecutivos, managers y equipos tecnicos

## Archivos

- `apuntes.md` — notas completas del curso con frameworks, comparativas y errores comunes
- `actividad-smart-questions/` — practica de formulacion de preguntas SMART
- `actividad-spreadsheets/` — ejercicios con funciones de Sheets
