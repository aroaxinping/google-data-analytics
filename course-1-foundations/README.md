# Course 1 — Foundations: Data, Data, Everywhere

**Duracion:** 13 horas | **Modulos:** 4 | **Fase del proceso:** Introduccion general

Introduccion al mundo del analisis de datos: que hace un analista, como piensa, que herramientas usa y como encaja el trabajo en una empresa. Cubre el framework Ask-Prepare-Process-Analyze-Share-Act que es la columna vertebral de todo el certificado.

## Contenido del curso

- Modulo 1: Introducing Data Analytics and Analytical Thinking — que es el analisis de datos, el ecosistema de datos y los cinco aspectos del pensamiento analitico
- Modulo 2: The Wonderful World of Data — el ciclo de vida del dato y el proceso de analisis Ask-Prepare-Process-Analyze-Share-Act
- Modulo 3: Set Up Your Data Analytics Toolbox — presentacion de las cuatro herramientas del certificado: Sheets, SQL, Tableau y Python
- Modulo 4: Become a Fair and Impactful Data Professional — etica de datos, equidad y tipos de empresa donde trabaja un analista
